## Exit assumption

**Y7 exit at 3.9× revenue.** This is not a chosen multiple — it is the
multiple PepsiCo actually paid for Poppi ($1.95bn cash plus $0.2bn contingent
against ~$500m of 2024 revenue), as disclosed in its
[Form 10-Q](https://www.sec.gov/Archives/edgar/data/77476/000007747625000053/pep-20250906.htm).
Using a strategic acquirer's disclosed multiple for the same category is
considerably more defensible than a comparable-company average.

## Probability-weighted seed return

Every deck shows the success case. This is the number a seed partner is
actually underwriting.

| Outcome | Probability | Seed proceeds | MOIC | Weighted |
|---|---|---|---|---|
| Failure / acquihire | 55% | ₹0 | 0× | ₹0 |
| Conservative | 25% | ₹159 Cr | 15.9× | ₹39.8 Cr |
| Base | 15% | ₹390 Cr | 39.0× | ₹58.6 Cr |
| Aggressive | 5% | ₹745 Cr | 74.5× | ₹37.2 Cr |

### **Expected value: ₹135.6 Cr on ₹10 Cr = 13.6× MOIC, 45.1% IRR over 7 years.**

A 55% failure weighting is deliberately harsh and appropriate for a
pre-revenue consumer brand against a funded incumbent. Even so, the expected
return clears the bar for a seed consumer fund, because the entry price is
low relative to the category's demonstrated exit values.

**What the weighting hides:** 55% of the time this returns nothing. The fund
maths works because of portfolio construction, not because this particular
company is likely to succeed. An honest pitch says that out loud.

## Sensitivity — what breaks the return

| Change | Effect on seed MOIC |
|---|---|
| Exit multiple 3.9× → 2.5× | 39.0× → 25.0× (base) — still strong |
| Y7 revenue base → conservative | 39.0× → 15.9× |
| One extra ₹75 Cr round before exit | ~15% further dilution; 39.0× → ~33× |
| Seed post-money ₹50 Cr → ₹80 Cr | 39.0× → ~24× — entry price is the biggest single lever |
| Exit at Y9 instead of Y7 | IRR 68.8% → ~52% (MOIC unchanged) |

The most sensitive variable is not revenue — it is **seed entry price**. A
₹50 Cr post-money is the difference between a fund-returning position and a
merely good one.
